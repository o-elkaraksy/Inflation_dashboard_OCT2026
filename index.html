METHODOLOGY

How to read this dashboard

Inflation rates

YoY compares the CPI index with the same month a year earlier. MoM compares it with the previous month. Rates are calculated from the source index points.

Contributions

Component contributions are shown in percentage points. The initial version uses weight-based allocations reconciled to the published aggregate rate; this is an analytical allocation, not an official statistical decomposition.

Monthly updates

Update the CSV in GitHub with the new monthly CPI column. The dashboard fetches the source when refreshed and detects the newest month automatically.
